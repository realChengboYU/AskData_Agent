 DeepData（AskData_Agent）项目前后端启动命令
================================================================

【环境要求】
- 前端：Node.js（配合 Vite）
- 后端：Python（项目自带 venv，位于 backend\.venv）
- 数据库：本地 Docker（用于智能体记忆 PostgreSQL，库名 askdata_memory）

----------------------------------------------------------------
 第一步：启动 PostgreSQL（只跑一次，后续无需重复）
----------------------------------------------------------------
    cd backend
    docker compose up -d

   （检查：docker ps 应看到 askdata-postgres 状态为 Up (healthy)。）

----------------------------------------------------------------
 第二步：启动后端 FastAPI（端口 8100）
----------------------------------------------------------------
    cd backend
    python -m uvicorn app.main:app --host 127.0.0.1 --port 8100 --reload

   （提示：
     · 端口 8000 已被其它服务占用，所以后端改用 8100。
     · 可选：配置真实 LLM 请在 backend\.env 设置 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL；
       不配置则智能体走模板演示答案，记忆照常读写。）

----------------------------------------------------------------
 第三步：启动前端 Vite（端口 5173）
----------------------------------------------------------------
    cd frontend
    npm install        # 首次运行装依赖，之后可跳过
    npm run dev

   浏览器打开： http://127.0.0.1:5173

----------------------------------------------------------------
 备注
----------------------------------------------------------------
- 前端通过 vite 把 /api 代理到后端 127.0.0.1:8100（见 frontend/vite.config.js）。
- 智能体长短记忆存到本地 Docker 的 PostgreSQL（askdata_memory 库）：
    · 短期记忆（多轮会话）→ checkpoints 等表
    · 长期记忆（按用户归档）→ langgraph_store 表
- 停止后端：在运行 uvicorn 的窗口按 Ctrl+C；停止数据库：docker compose down。
