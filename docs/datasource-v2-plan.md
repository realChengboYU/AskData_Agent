> 借鉴 SQLBot（dataease/SQLBot）数据源管理逻辑，结合 DeepData 现状与既有视觉体系制定。基于其 Docker 内前端 Vue + 后端 FastAPI 源码拆解。

## 一、目标

把 DeepData 数据源从「PG-only 基础增删改查」升级为「面向问数（NL2SQL）的数据源策展」：

- 用户连接数据库 → 测试连通 → 挑出要暴露给大模型的表和字段 → 补业务注释 → 问数时只基于这些表和字段。
- 安全：连接凭据加密存储，列表永不回传密码。

## 二、SQLBot 数据源管理 逻辑拆解

### 2.1 交互：三步向导（全屏底部抽屉）

| 步骤 | 名称 | 内容 |
| --- | --- | --- |
| 1 | 选择数据源 | 13 种数据库类型卡片（带图标），点选 |
| 2 | 配置信息 | 左：类型列表（可切换）；右：连接表单（800px 居中） |
| 3 | 选择表 | 搜索 + 全选 + 虚拟列表勾选表，显示「已选 / 总数」 |

编辑态跳过第 1 步，直接从配置进入。

### 2.2 支持的数据库类型（13 种，各带图标）

`excel` / `MySQL` / `Oracle` / `PostgreSQL` / `SQL Server` / `ClickHouse` / `达梦` / `Doris` / `Redshift` / `Elasticsearch` / `Kingbase` / `StarRocks` / `Hive`

- 有 Schema 概念（才显示 Schema 下拉）：`sqlServer` / `pg` / `oracle` / `dm` / `redshift` / `kingbase`
- 顶部显示「支持版本」提示，如 pg 9.6+、mysql 5.6+、oracle 12+、sqlServer 2012+、es 7+

### 2.3 连接配置字段（按类型自适应）

- 通用：名称（不超过 50）、描述（不超过 200）
- 主机类：主机 / 端口 / 用户名 / 密码（可显隐）/ 数据库 / 附加 JDBC / 超时（0 到 300）/ 连接池（1 到 500）
- 按类型：Oracle 连接方式（`service_name` / `sid`）、SQL Server 低版本开关、MySQL 与 Doris 的 SSL 开关、Schema 下拉（带「获取 Schema」按钮实时拉取）
- Excel：文件上传（xlsx / xls / csv，不超过 50MB）；SQLite：文件路径

### 2.4 连接测试（关键交互）

- 独立「测试」按钮：填完即测，返回连通 bool。
- 「下一步」自动先测通，测通才拉表并进下一步；测不通不给过。

### 2.5 选表（问数命脉）

- 搜索框 + 全选（半选态）+ 虚拟滚动表清单，每行一个勾选。
- 选中数超过 30 弹警告。
- 每张表存 `table_name` + `table_comment`。

### 2.6 保存

- 新建：提交「配置 + 选中表」
- 改配置 / 改表：分别走 update / chooseTables

### 2.7 建后管理（数据源详情里）

- 表 / 字段级勾选（`checked`），字段可单独开关
- 自定义注释 `custom_comment`（表、字段都能改）——帮大模型理解字段含义
- 数据预览、字段枚举值（distinct）
- 表关系（给 NL2SQL 生成 join）
- 同步字段（从库重拉 schema）
- Embedding（对 schema 做向量，RAG 检索）
- 推荐问题配置
- Excel 导入（上传、解析、写入应用 PG）；Schema 导入 / 导出

### 2.8 安全

- 配置（含密码）在前端整体 AES-ECB 加密后存入 `configuration` 字段，后端解密。
- 注意：前端硬编码密钥 `SQLBot1234567890`，本质是混淆不是真加密。

## 三、可借鉴点 与 我们的取舍

| SQLBot 能力 | 是否借鉴 | 优先级 | 理由 |
| --- | --- | --- | --- |
| 表选择（勾选） | 借鉴 | P0 | 问数准确率命脉，LLM 只看选中表 |
| 自定义注释（表 / 字段） | 借鉴 | P0 | 直接提升 NL2SQL 命中率 |
| 测试 gating（测通再拉表） | 借鉴 | P0 | 防呆，体验闭环 |
| 配置加密存储 | 借鉴（改） | P0 | 安全；改成服务端密钥 |
| 数据预览 | 借鉴 | P1 | 降低「连的到底是哪份数据」的不确定 |
| Schema 下拉（实时拉） | 借鉴 | P1 | PG 天然有 schema |
| 字段级勾选 + 枚举 | 借鉴 | P1 | 进一步收窄检索面 |
| 多库类型 | 借鉴（分期） | P1 | 先 PG 加 MySQL，结构留扩展 |
| 高级连接项（ssl / timeout / pool） | 借鉴 | P1 | 连接稳定性 |
| 支持版本提示 | 借鉴 | P2 | 低成本 |
| 表关系（join） | 借鉴 | P2 | 多表问数才需要 |
| Embedding / RAG | 借鉴 | P2 | 已有向量栈，后接 |
| 推荐问题 | 借鉴 | P2 | 冷启动引导 |
| Excel 导入 | 借鉴 | P3 | 非核心 |
| Schema 导入 / 导出 | 借鉴 | P3 | 运维向 |

## 四、DeepData 方案（数据源 v2）

### 4.1 设计方向

- 视觉 DNA（延续现有）：navy 深蓝（权威、基建）、primary 主蓝（动作、激活）、mist 雾蓝（软底、选中）、中浅蓝（次级）、绿（已连接、可用）、玫红（错误）。
- 字体：Geist 做 UI，等宽做连接串、DDL、字段类型。双字体明确分工，「数据工程师」气质。
- 层级清晰：标题大、正文小、技术串等宽。
- 记忆点（只花在一处）：配置步的「连接串预览」深蓝块 + 选表步的「schema 策展」双栏；其余克制。
- 动效：只回应人的动作（测试中、已连、勾选表、展开字段），不做入场动画。

### 4.2 布局与线框

- 延续「侧边栏常驻 + 主区视图」；新建是主区三步（不是弹窗）。
- 配置步：单栏表单（760px）+ 连接串预览深蓝块。
- 选表步：双栏，左「表清单」（搜索、全选、勾选），右「表详情」（字段勾选、注释、数据预览）。

```
[数据源列表页]                 [新建·第2步 配置]
 数据源        [＋ 新建数据源]    名称 [____________]
 ┌────────────────────────┐    描述 [____________]
 │ ● 生产库(使用中) PG 12表 │    主机 端口 用户 密码(•••)
 │ ○ 测试库         PG  5表 │    数据库 [____________]
 └────────────────────────┘    ┌连接串预览·深蓝等宽┐
                                 │ postgresql+psycopg://… │
 [新建·第3步 选表]              └────────────────────┘
 ┌───────────┬────────────────┐    [测试]        [下一步]
 │ 搜索表      │ 表 orders      │
 │ ☑ 全选(3/8)│ 字段           │
 │ ☑ orders   │ ☑ id    int    │
 │ ☑ users    │ ☑ amount dec   │
 │ ☐ logs     │ ☐ memo  text   │
 └───────────┴────────────────┘
   注释 [____________]
   [预览 10 行]     [上一步] [保存]
```

### 4.3 数据模型（后端）

- `data_sources`：现有字段 + 增 描述 / 类型名 / 状态 / 表数；`configuration` 改存加密整体。
- 新增 `data_source_tables`：ds_id / 表名 / 表注释 / 自定义注释 / 是否启用。
- 新增 `data_source_fields`：ds_id / 表id / 字段名 / 字段类型 / 字段注释 / 自定义注释 / 是否启用。
- （P2）表关系 / embedding / 推荐问题。

### 4.4 后端 API（对齐 SQLBot 子集）

- 测试：提交配置，返回连通 bool
- 拉表：提交配置，返回表清单（表名 + 注释）
- 拉字段：某表，返回字段清单
- 预览：某表，返回前 N 行
- CRUD + 选表 + 改表注释 + 改字段
- （P1）拉 Schema；（P2）关系 / 枚举 / 同步 / 推荐问题

### 4.5 安全

- 服务端加密（服务端密钥，env 注入；不前端硬编码）。
- 列表永不回传密码；连接串只在配置步显示且密码打码。

### 4.6 分期

- P0：三步向导 + 表选择 + 自定义注释 + 测试 gating + 配置加密 + 数据预览（先 PG）
- P1：MySQL + Schema 下拉 + 字段级勾选 + 高级连接项 + 字段枚举
- P2：表关系 + Embedding / RAG + 推荐问题 + 更多库
- P3：Excel 导入 + Schema 导入 / 导出

### 4.7 开放问题（待拍板）

- 加密密钥：服务端 env 一把，还是接密钥服务？
- 选表上限：SQLBot 是 30，建议同。
- 是否需要「数据源分组 / 工作空间」（SQLBot 有 oid / ws）？
- 权限 / 行级权限（SQLBot 有，我们暂不做）？
